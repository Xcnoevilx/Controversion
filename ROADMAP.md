# Controversion Roadmap

## Phase 1 — MVP

Build the smallest usable version of Controversion.

- Topic pages
- Claim summaries
- Evidence for and against each claim
- Source links and citations
- Source credibility information
- Alternative explanations
- Categories and tags
- Search
- Popular and trending topics

## Phase 2 — Community

Add user participation.

- User accounts
- Comments and discussion
- Belief/confidence ratings
- Topic submissions
- Evidence submissions
- Duplicate-topic detection
- Reporting and moderation tools

## Phase 3 — Research System

Build tools that help collect and organize information.

- Automated topic discovery
- Research assistant/bot
- Source collection
- Claim extraction
- Duplicate detection
- Trending-topic detection
- Evidence classification
- Human review before publication

## Phase 4 — Critical-Thinking Tools

Help users evaluate information rather than simply consume it.

- Source evaluation
- Claim-vs-evidence visualization
- Timeline views
- Compare competing hypotheses
- Identify missing evidence
- Explain uncertainty
- Show how conclusions change as evidence changes

## Phase 5 — Education

Create interactive learning material.

- Media literacy
- Phishing and scam recognition
- Deepfake awareness
- Source verification
- Logical fallacies
- Confirmation bias
- Evaluating statistics and scientific claims

## Long-Term Goal

Controversion should become a structured library of disputed ideas where users can trace:

Claim → Evidence → Source → Counterevidence → Alternative Explanation → Conclusion

The platform should make it easier to investigate a controversy without requiring users to accept the position of Controversion itself.
